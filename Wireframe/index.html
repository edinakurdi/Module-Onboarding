What is a README file?

A README file is a text file that provides information about a project. It contains the purpose, how to use the project, and any other relevant information. It should be clear and concise, and should be written in a way that is easy to understand for anyone who may be interested in the project.

What is the purpose of a wireframe?

A wireframe is like a blueprint for a website. It is a visual plan of how we want the website to look. As with a blueprint, this helps organise our ideas about the website, and allows us to follow a planned structure when we start building the website. It is also useful for comparing different versions before we start building, so we dont waste time building something we don't like.

What is a branch in Git?

A branch in Git is a version of a repository. There is a main branch, the original one, and there can be several different versions, potentially created by different people, allowing collaboration without overriding each other's work. When someone finishes working on their branch, they can then merge it into the main branch through a process of a pull request which asks for the changes to be reviewed. The changes can be approved and merged to the main branch, or rejected and sent back for changes. The two benefits of this system are reviewing changes that are made to a repository and not overriding each other's work.
